# Sigma Provider

Use the Sigma provider to interact with your Sigma Computing organization.

Configure API client credentials with `SIGMA_CLIENT_ID` and
`SIGMA_CLIENT_SECRET`. Set `SIGMA_BASE_URL` to the API host for the cloud
region where your Sigma organization is hosted.

```terraform
terraform {
  required_providers {
    sigma = {
      source = "civitaspo/sigma"
    }
  }
}

provider "sigma" {
  base_url = "https://api.sigmacomputing.com"
}
```
